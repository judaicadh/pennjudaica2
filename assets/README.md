# Milgroym reference image

`milgroym-1922.jpg` is the 1922 first-issue cover of *Milgroym*, by Franzisca
Baruch and Ernst Böhm. Source: Stanford Humanities Center, Barbara Mann,
“The Materiality of the Book in Yiddish Modernism: An Essay.”

Image: https://shc.stanford.edu/sites/default/files/dibur-v10i01-mann-figure01.jpg
Article: https://shc.stanford.edu/arcade/publications/dibur/peripheral-modernisms/materiality-book-yiddish-modernism-essay
Design research: https://ingeveb.org/articles/rachel-wischnitzers-and-franzisca-baruchs-collaboration

The historical cover is credited in the interface. Collection item images are
shown without a sepia effect or other recoloring. `milgroym.css` contains the
portal's contemporary interpretation of the periodical's typography and layout.

`pomegranate-woodcut.png` is the reference artwork supplied by the user. The original file is preserved unchanged; CSS uses its luminance as a single-color print mask.
